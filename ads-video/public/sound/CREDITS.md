# Sound effects

The short effects a reel plays. All three were released by their makers under
Creative Commons 0 (public domain), and came by way of Remotion's sound
library (remotion.dev/docs/sfx).

| File | Plays when | Source |
| --- | --- | --- |
| `whip.wav` | a new photo arrives | "SWSH_Badminton Racquet_Recording_01_JW Audio" by JW_Audio, freesound.org/s/838766 |
| `whoosh.wav` | the ask comes up | "Woosh" by 1bob, freesound.org/s/831936 |
| `switch.wav` | a label lands | "UI Audio - Switch 35" by kenney.nl |

Music is not kept here: this repository is public, and a music track's
licence covers using it in an ad, not handing the file out. Tracks live in
the app's own storage (the `adMusic` table) and are fetched when an ad is drawn.
